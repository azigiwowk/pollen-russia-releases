# Pollen Russia Releases

Публичный канал тестовых обновлений приложения «Пыльца».

В этом репозитории не хранится исходный код приложения. Здесь будут публиковаться только:
- APK тестовых версий;
- `version.json` с номером актуальной версии;
- краткое описание изменений.

Исходный код находится в приватном репозитории `azigiwowk/pollen-russia-app`.
