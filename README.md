# Аллергофон — Releases

Публичный канал тестовых обновлений Android-приложения **«Аллергофон»**.

В этом репозитории не хранится исходный код приложения. Здесь публикуются:
- подписанный APK тестовой версии;
- `version.json` для встроенного механизма обновлений;
- краткое описание изменений;
- служебные файлы процесса публикации.

Исходный код находится в приватном репозитории `azigiwowk/pollen-russia-app`.

APK публикуется автоматическим workflow только после успешной сборки точного финального SHA из ветки `main`.
